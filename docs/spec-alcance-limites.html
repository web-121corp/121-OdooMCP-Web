01 / IDEA CENTRAL

El MCP conecta asistentes compatibles —como LibreChat, ChatGPT o Flowise— con datos autorizados de Odoo. El usuario pregunta en lenguaje natural; el servidor traduce, valida, consulta y devuelve una respuesta estructurada.

A /

Cliente 360

Identidad, contactos, responsables, etiquetas, CRM, ventas, proyectos, tareas, actividades, pendientes, facturas y antigüedad.

B /

Personas y capacidad

Ausencias, saldos de tiempo libre, disponibilidad de personas, capacidad de proyectos y horas registradas.

REGLA DE ORO

Consultar, cruzar y explicar.
No modificar.

El producto está pensado para dar contexto operativo sin convertirse en otra pantalla de administración.

03 / Límites

LO QUE NO HACE

Leer mucho.
Cambiar nada.

BLOQUEADO / 01

No escribe en Odoo

No permite crear, editar, borrar, duplicar, publicar, enviar mensajes ni ejecutar botones o acciones de servidor.

BLOQUEADO / 02

No salta permisos

Odoo sigue decidiendo qué puede ver cada usuario mediante ACLs, reglas de registro, campos permitidos y compañías.

BLOQUEADO / 03

No es un ERP

No reemplaza la interfaz de Odoo, no mantiene una copia completa de sus datos y no opera procesos por su cuenta.

BLOQUEADO / 04

No inventa contexto

Si Odoo no expone el dato o el usuario no tiene acceso, la respuesta debe reflejar esa ausencia.

05 / Seguridad

SEGURIDAD POR DISEÑO

La confianza no
se supone.

AUTH

Bearer API key

La llave se verifica y se usa solo durante la solicitud. No se confía en headers de identidad enviados por el cliente.

✓
DATA

Secretos fuera del navegador

Las credenciales permanecen en el servidor. No llegan a n8n, al navegador ni a la memoria del modelo.

✓
SCOPE

Allowlist de lectura

El adaptador solo despacha métodos permitidos. Acciones de escritura, borrado y server actions se rechazan antes de la red.

✓
SESSION

Sesiones controladas

Sesiones opacas, expiración, revocación y tokens CSRF para el flujo embebido.

✓
TRACE

Auditoría y red privada

Eventos de seguridad, límites de paginación, PostgreSQL interno y despliegue detrás de HTTPS/proxy controlado.

✓
